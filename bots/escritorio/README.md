# Escritório

Agente para o trabalho de escritório: documentos Word, planilhas Excel/CSV, apresentações e PDFs.

- Instala as skills `word`, `planilhas`, `apresentacoes` e `pdf`.
- Usa formatos brasileiros (datas, R$, ABNT básico) e confere o arquivo antes de entregar.
- Não inventa números nem fontes; pergunta ou marca o que falta.
- Sem conectores obrigatórios, sem credenciais e sem rotinas iniciais.
