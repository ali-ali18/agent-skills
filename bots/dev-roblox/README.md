# Dev Roblox

Agente pronto para desenvolver jogos Roblox em Luau com Rojo dentro da VM.

- Usa a skill `roblox` (instalada no escopo do agente).
- Publica somente em um lugar de TESTE que você informar, com `versionType=Saved` por padrão.
- A chave de API do Roblox nunca faz parte do modelo: você a guarda no cofre depois de instalar.
- Sem rotinas iniciais.
